## 1. デザインコンセプト

**「Precision in Steel — 一枚の板が、製品になるまで。」**

長村製作所の本質は「精密板金加工の一貫体制」と「電話ボックスの型材から派生した空間ブランド（SMOX / KOVAKO / Monobo）」にあります。
そこで、サイト全体を **鋼の質感を持つダーク基調** で統一し、工場の実写映像（元サイトの動画）と、
**Three.js で手続き的に生成した板金部品がレーザーカット→抜き→曲げ→溶接→箱物へ組み上がるスクロール連動 3D** を軸に、
「技術力が見える」コーポレートサイトを目指しました。既存サイトの情報は全項目を保持し、ページ構成も踏襲しています。

### 技術スタック

- **素の HTML / CSS / JS**（フレームワーク・バンドラー不使用）。`src/pages/*.mjs`（テンプレートリテラル）→ `tools/build.mjs`（依存ゼロの Node スクリプト）→ ルートに 17 ページの静的 HTML を生成し、生成物をコミット（Actions 側のビルド失敗リスクをゼロに）

## 3. 写真・加工・3D表現

### 使用素材（すべて元サイトの実物）
- **元サイトの動画 `top_movie.mp4`（1920×1080）** をヒーロー背景に採用（720p に再エンコードして 1.9MB mp4 ＋ 2.1MB webm、ポスター画像付き、`prefers-reduced-motion` / `saveData` 時は再生しない）。
- 同動画から **溶接（4.6s）／レーザー（7.5s）／組立（11.6s）／工場（1.5s）** の高解像度フレームを切り出し、下層ページのヒーロー・OG 画像に使用。元サイト内で最も解像度が高い実写素材です。
- 採用サイトの写真（1500×1000 の集合作業写真、1200×800 の職種写真、社長ポートレート）、経営方針ページの工場全景・社員集合写真を各所に。
- 製品写真 27 点、設備写真 19 点、技術写真 12 点、ISO 登録証 3 点、ブランド画像（SMOX/KOVAKO/Monobo）を WebP 化。

### 加工
- sharp で **彩度 −8%・コントラスト +6%** の統一グレーディング（実写のみ。製品カットアウト・書類は無加工）、WebP（q78–82）、大判は 1920/1280/768 の複数サイズ＋`srcset`。
- ダーク面ではグラデーションオーバーレイと `filter: saturate()` で写真を背景に沈め、テキストのコントラストを確保。

### 3D / WebGL（トップページ PROCESS）
- 外部モデルは使わず **手続き的に生成**：ベース板＋4枚のフラップ（ヒンジ用 Group）で板金の展開図を構成。
- **フェーズ**：設計（青いワイヤーフレームと折り線）→ レーザーカット（展開図の輪郭をダッシュラインで描画しつつレーザーヘッドが移動、金色のスパーク粒子を放出）→ 抜き（Canvas に描いた穴パターンを `alphaMap`＋`alphaTest` でリアルタイムに打ち抜き）→ 曲げ（4フラップが順に 90° 折れ上がる）→ 溶接（コーナーで青白いポイントライトが明滅しスパーク）→ 組立・検査（ターンテーブルで見せる）。
- 材質は `MeshPhysicalMaterial`（metalness 1.0、Canvas 生成の**ヘアライン・ラフネスマップ**、クリアコート）＋ `RoomEnvironment` の PMREM 反射。
- ScrollTrigger で 320vh ピン留め、`progress` をイージングで追従。6ステップのキャプションと進捗バーが同期。
- **WebGL が使えない環境**では静止画（レーザー加工のフレーム）にフォールバックし、キャプションだけがスクロールで切り替わる（例外は投げない）。`prefers-reduced-motion` では完成状態を静的表示。

## 4. 工夫した点

- **情報の網羅と正確さ**：全ページを `curl` で取得しパーサで抽出、ブログは WordPress REST（`?rest_route=`）で 895 件を取得。設備表は 69 行を型式・仕様・台数まで転記（数値・No. は原文どおり、`docs/content-inventory.md` で照合）。
- **公式ロゴの活用**：ヘッダー・フッターに公式ロゴ（白／赤）を使用し、アクセントカラーもロゴの赤から採用。ブランドページは各ブランドのロゴを白いチップ上に表示。
- **日本語タイポグラフィ**：`palt`、行間 1.9、`text-wrap: balance/pretty`、長い型式番号は `overflow-wrap: anywhere`、キャッチはフレーズ単位で改行制御。
- **アクセシビリティ**：スキップリンク、`:focus-visible` リング、ドロップダウンは `aria-expanded`／`focus-within`／Esc 対応、アコーディオンは `aria-controls`、ライトボックスは `<dialog>`、全画像に alt、`prefers-reduced-motion` で全モーション停止、ページ内ナビは `aria-current`。
- **表示速度**：ヒーロー以外は `loading="lazy"`、`srcset`、WebP、YouTube／Google Maps はクリック時または遅延読み込み、フォントは `display=swap`、ライブラリはローカル同梱（外部 CDN 障害の影響なし）。全 17 ページのアセット合計 10MB のうち、1ページが実際に読み込むのは概ね 0.5〜3MB。
- **お問合せ導線**：ヘッダー CTA、モバイル固定バー、全ページ末尾 CTA（電話＋フォーム）、ブランドページは各所に専用フォーム CTA。
- **ブログの存在感**：トップに最新 5 件、ブログページは年別・検索付きの全記事一覧。

## 5. 妥協した点・判断

- **お問合せフォーム**：サーバーが無く、一般窓口メールアドレスも公開されていないため、入力内容をクリップボードにコピーして公式 Microsoft Forms を開く方式にしました（`mailto:` は採用窓口のみ）。
- **ブランドサイト（SMOX/KOVAKO/Monobo）**：LP の全テキスト・仕様・FAQ は移植しましたが、コラム記事本文・導入事例詳細・料金シミュレーションの計算ロジックは元サイトへリンク（価格計算の内部係数はサイトから取得できないため）。
- **ブログ本文**：課題の許容範囲に従い、タイトル・日付・リンクのみ移植。
- **社員数の表記差**：会社概要「58名（2026年1月時点）」と採用サイト「59名（2025年8月1日時点）」は元サイトどおり、それぞれの文脈で併記しました。
- **設備表の No.**：溶接加工の「No.11 ガス溶接機」など原文の欠番も改変せず保持。試験・計測器の仕様「0. ～2×1072×107」も原文どおり（元 HTML に上付き指定が無いため）。
- **フォント**：Google Fonts を利用（外部依存）。ネットワーク不可の場合はシステムフォントにフォールバック。

## 6. 既知の問題

- ヘッドレス Chromium のモバイルエミュレーションでは WebGL コンテキストが生成できず、フォールバック表示で検証しました。実機モバイル GPU での 3D 描画は未検証です（フォールバックは正常動作を確認）。
- Google Maps 埋め込みはサードパーティ Cookie 設定によりブラウザ側で警告が出ることがあります（元サイトと同じ embed URL）。
- ページ内ナビ（スティッキー）は項目が多いページ（Monobo、設備）でモバイルでは横スクロールになります（意図した挙動）。
- 動画は 720p に圧縮しているため、4K モニタでは元の 1080p よりやや甘く見えます（サイズ優先の判断）。
