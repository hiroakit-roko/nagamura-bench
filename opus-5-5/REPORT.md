## 1. デザインコンセプト — 「FROM FLAT TO FORM」

長村製作所の仕事は「一枚の金属板を、社会インフラを支える確かなかたちにすること」。
そして同社のロゴは、帯状の板を折り曲げて組んだような**アイソメトリックの立方体**です。
この2つを重ね、サイト全体を「平板 → 立体」の物語として設計しました。

- **トップのファーストビュー**：工場を走る実写映像（公式トップ動画をグレーディング）の上に、WebGL で描いた**ヘアライン仕上げのステンレス展開図**が浮かびます。
- **スクロールすると**、その展開図が
  **① 設計（青焼き風の輪郭線と曲げ線） → ② 抜き（タレパンのように穴が1つずつ打ち抜かれる） → ③ 曲げ（4辺と天板が順に90°折れる） → ④ 溶接（コーナーに火花とビード） → ⑤ 塗装（下から赤く塗り上がる） → ⑥ 検査（レーザー面が走査） → ⑦ 出荷（等角図の赤いキューブ＝ロゴの形へ）**
  と変化し、同社の「設計から出荷まで一貫対応」を、言葉ではなく体験として伝えます。
- CAD図面・寸法線・トンボ（レジストレーションマーク）をモチーフにした細い罫線、モノスペースの工程番号など、**図面の精度感**を全体の装飾言語にしています。

## 2. 技術スタック
- **静的マルチページ（14ページ）**。自作の小さなジェネレータ（`build.mjs` + `src/pages/*.mjs` のテンプレート関数）で `dist/` に HTML を出力
- **esbuild** で JS/CSS をバンドル・圧縮（コード分割：3D・設備フィルタ・ブログ検索・問合せ補助はページ単位で遅延読込）
- **Three.js 0.180**（MeshPhysicalMaterial の `onBeforeCompile` によるシェーダー拡張、RoomEnvironment による映り込み）
- 画像は **sharp** で WebP 化・多サイズ生成（`srcset`/`sizes`）、ダブルトーン加工、OGP画像生成
- 動画フレーム抽出は macOS の AVFoundation（Swift）で実施
- フレームワーク非依存の素の JS（IntersectionObserver / View Transitions API / `<dialog>` / `Intl.Segmenter`）

## 4. 写真・加工・3D表現

- **写真はすべて同社サイト群の実物**（工場・設備・製品・社員・社長）。汎用のストック写真は不使用。
  - 公式サイトの写真は 360px 前後と小さいため、ヒーローや大判には**採用サイト（1200px）・社長ブログのヘッダー（2000px）・トップ動画**の高解像度素材を優先的に割り当てました。
  - 加工：WebP化（最大2000px・480/960/1440の多サイズ）、ページヒーローはグレースケール寄せ＋コントラスト＋赤のグラデーションでトーン統一、CTA背景は工場全景のダブルトーン、OGPは社長写真をトリミング＋コピーを合成。
- **トップ動画**：デスクトップのみ読込（スマホ・省データ・視差効果を減らす設定ではポスター画像）。
- **3D（Three.js）**：外部モデルは使わず、すべて手続き的に生成
  - 板厚のある6枚のパネルを十字の展開図として配置し、ヒンジ（ピボット）ごとに順番に折り曲げ
  - **パンチ穴・ルーバー・ノックアウト**はジオメトリではなくフラグメントシェーダーで生成し、進捗に応じて1穴ずつ「打ち抜かれる」
  - **塗装**はワールド座標の高さで下から塗り上がるワイプ、**溶接**は火花パーティクル（重力・床バウンド）＋発光ポイントライト＋ビードの成長、**検査**は加算合成のレーザー面
  - 金属感：MeshPhysicalMaterial（異方性反射）＋Canvasで生成したヘアラインの粗さマップ＋RoomEnvironment の映り込み
  - 最後のカメラは等角図（isometric）に収束し、赤いキューブが**ロゴマークと同じ見え方**になります

## 5. 工夫した点
- **情報の網羅**：元サイトの全ページ（上記の除外分を除く）＋採用サイト＋自社ブランド3サイトの要点を収録。設備表は原文どおり（No.の飛び、試験機の仕様表記も改変せず）。
- **数値の扱い**：「創業◯年」は元サイトと同じ規則（1938年5月5日起算）でビルド時とブラウザ実行時の両方で計算。社員数は会社概要の「58名（2026年1月時点）」と採用サイトの「59名（2025年8月1日時点）」を、それぞれ出典どおりの日付付きで掲載。「保有設備133台」は設備概要の台数を合計した値で、その旨を注記。
- **導線**：ヘッダーに電話番号とお問合せを常設、スマホは画面下に「電話／お問合せ」の固定ボタン、全ページ末尾に大きな問合せCTA。採用は職種→数字→福利厚生→要項→エントリーの順に設計。
- **お問合せ**：サーバーが無いため、入力内容を整形してクリップボードにコピーし、**用件ごとに正しい公式フォーム**（一般／SMOX／KOVAKO／Monobo）へ誘導。採用は `mailto:` に本文を入れて起動。
- **アクセシビリティ**：スキップリンク、ランドマーク、パンくず、見出し階層、`aria-expanded` のメガメニュー（ホバー・クリック・Esc対応）、キーボード操作可能なタブ（矢印キー）、`<dialog>` のライトボックス（←→・Esc）、フォームのエラー通知（`aria-invalid` / `aria-live`）、全画像の alt、`prefers-reduced-motion` で全アニメーション・動画・3Dの自動演出を停止。
- **表示速度**：画像は WebP＋`srcset`＋`loading=lazy`、Three.js はトップのみ動的読込、画面外では描画ループ停止、ブログ全記事データ（約300KB）はブログページでのみ取得。

## 6. 妥協した点・判断
- **ブログ本文の移植はしていません**。社長ブログは895本と膨大で、日々更新されているため、タイトル・日付・冒頭抜粋・元記事リンクのアーカイブとして再設計しました（ビルド時点のスナップショット）。
- **採用条件の食い違い**：コーポレートサイト側の旧ページ（/info/recruit/：年間休日120日以上・勤務時間8:15〜・短大卒188,000円）と採用サイト（年間休日127日・8:25〜・188,800円）で数値が異なるため、**より新しい採用サイトを正**とし、旧ページの内容は折りたたみで「旧」と明記して併記しました。
- **塗装工程**：元サイトは「一貫対応」と「協力工場にて塗装」の両方を記載しているため、工程ストーリー内の塗装は「協力工場との連携」と表現しています。
- 採用サイトの「Hello world!」（WordPress初期投稿）は掲載対象外としました。
- **サイトオーナーのご要望により、社長ブログ以外のもう一つのブログ（DX・デジタルマーケティングをテーマとした別ブログ）は意図的に掲載対象外としました**。専用ページ・記事データを作らず、ナビ・フッター・モバイルメニュー・サイトマップ・トップページからのリンクや言及も一切ありません。
- 自社ブランド（SMOX/KOVAKO/Monobo）は独立したLPサイトのため、新サイトでは要約＋仕様＋公式サイト/資料請求への導線とし、コラム記事（SMOX 47本・KOVAKO 16本）や料金シミュレーターは移植していません。
- Google マップは元サイトと同じ埋め込み（外部iframe）を使用しています。

## 7. 既知の問題
- WebGL 非対応環境では 3D を表示せず、工程テキストを通常の縦並びで表示します（`no-gl` フォールバック）。
- 設備表「絶縁抵抗計」の仕様は元サイトの表記（`DC100,200,500V /0. ～2×1072×107`）をそのまま掲載しています（上付き文字が失われた表記と思われますが、推測で修正していません）。
- ブログのアーカイブはビルド時点（2026-09-23）までの記事です。
