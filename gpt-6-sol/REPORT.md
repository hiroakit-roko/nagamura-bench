# 株式会社長村製作所 Webサイト リニューアル報告

## デザインコンセプト

「精度を、視覚で伝える」。鉄の暗色、設計図を思わせる細い罫線、溶接火花のオレンジを基調にした工業系エディトリアルデザイン。トップは実際の工場映像と大きな日本語見出しで始め、技術・設備・製品へ順に進む構成にした。英字の補助ラベルに Barlow Condensed、日本語に Noto Sans JP を採用。

## 技術スタック

HTML / CSS / JavaScript の静的マルチページサイト。ビルド依存なし。GitHub Pages のサブディレクトリ配信に対応するため、全ページで相対リンクを使用。モバイルメニュー、スクロール位置表示、製品画像の拡大表示は軽量なJavaScriptで実装した。`prefers-reduced-motion` では動画を停止して静止画像に切り替える。

詳しい項目別の対応は `docs/content-inventory.md` を参照。

## 写真・動画・表現

元サイトの実写真と製品写真を `assets/` にローカル保存。トップでは公式の工場動画を背景に使用。技術・設備ページでは現場写真を大きく見せ、製品ページでは元の製品写真を一覧と拡大表示で活用した。写真の彩度とコントラストはCSSで表示時に調整。架空の製品・設備・人物やCGを実物として掲載していない。

## 工夫と判断

- 設備表の型式・仕様・台数、会社基本情報、沿革、FAQ、製品名は元ページの記載を保持。
- 会社概要の社員数58名（2026年1月）と採用サイトの59名（2025年8月）は掲載時点が異なるため、それぞれ時点を併記。
- お問い合わせは公式フォームへ誘導。静的サイト上で送信できるように見せかけるフォームは設けない。
- ブランド別の3つの製品サイトはそれぞれ概要ページを新設し、詳細仕様・事例・見積りは公式製品サイトへ接続した。これらの製品別サイトは本文量が非常に多いため、全ページの本文複製は行っていない。

## 既知の問題

- 元サイトの採用ページは更新時点の異なる統計値を掲載しており、会社概要と人数が一致しない。新サイトでは出典時点を明記した。
- 外部の公式フォーム、製品別詳細サイト、ブログ記事、Google Maps、YouTube は外部サービスの稼働に依存する。
